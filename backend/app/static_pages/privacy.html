Política de Privacidad de FitMoi

Última actualización: 24 de agosto de 2026

FitMoi es una aplicación personal y de un solo usuario de seguimiento nutricional y de actividad física, desarrollada y utilizada por su propio autor. No es un servicio comercial ni multiusuario: no hay registro de terceros ni venta de datos.

1. Responsable

El responsable del tratamiento de los datos es el titular de la aplicación, contactable en moisesamselembenz@gmail.com.

2. Qué datos se tratan

  • Perfil: datos que el usuario introduce (edad, sexo, altura, peso, objetivo y nivel de actividad) para calcular objetivos nutricionales.
  • Comidas: fotos, descripciones de texto y los valores nutricionales estimados a partir de ellas.
  • Actividad física: sesiones registradas manualmente y, cuando se conecta la cuenta de Whoop, los datos de entrenamiento que FitMoi obtiene del API de Whoop.

3. Datos obtenidos de Whoop

Si el usuario conecta su cuenta de Whoop, FitMoi accede —con su autorización explícita mediante OAuth— a sus datos de entrenamiento (workouts): entre ellos la energía gastada (calorías), la duración, la frecuencia cardíaca y métricas asociadas al esfuerzo.

  • Estos datos se usan únicamente para calcular el gasto energético diario dentro de FitMoi y complementar el seguimiento nutricional del propio usuario.
  • No se comparten con terceros ni se usan con fines publicitarios o de perfilado.
  • Se almacenan en la base de datos privada de la aplicación (ver punto 5).

4. Análisis de comida con IA

Para estimar porciones, calorías y macronutrientes, las fotos y descripciones de comida se envían al servicio de IA de Anthropic (Claude), que actúa como encargado del tratamiento a estos únicos efectos. No se le envían datos de Whoop ni datos identificativos del usuario.

5. Dónde se guardan los datos

Los datos se almacenan en una base de datos PostgreSQL gestionada y en el almacenamiento de la propia infraestructura de despliegue (Railway). El acceso a la aplicación está protegido por un token de acceso privado.

6. Conservación y borrado

Los datos se conservan mientras el usuario los mantenga en la aplicación. Como titular único, el usuario puede eliminar sus registros en cualquier momento desde la propia aplicación o solicitando su borrado en la dirección de contacto.

7. Revocar el acceso a Whoop

El usuario puede revocar en cualquier momento el acceso de FitMoi a sus datos de Whoop desde la configuración de aplicaciones de su cuenta de Whoop (app.whoop.com). Al revocarlo, FitMoi deja de sincronizar nuevos datos de entrenamiento.

8. Cesión a terceros

No se venden, alquilan ni ceden datos a terceros. Las únicas comunicaciones de datos son las estrictamente necesarias para el funcionamiento descrito: Anthropic (análisis de comida) y la infraestructura de alojamiento.

9. Cambios en esta política

Esta política puede actualizarse. La fecha de la última revisión figura al inicio del documento.

10. Contacto

Para cualquier cuestión sobre privacidad, escribe a moisesamselembenz@gmail.com.
